# Frontend - Dashboard Financeiro (ApexFinance)

Interface web moderna com estilo de plataforma financeira premium (Dark Mode, Glassmorphism, Chart.js, tipografia Plus Jakarta Sans).

## Arquivos
- `index.html`: Layout e estrutura da interface.
- `css/style.css`: Design moderno (Glassmorphism, sombras neon sutis, gradientes, responsividade).
- `js/app.js`: Integração de API (GET, POST, PUT, DELETE) e renderização gráfica.
